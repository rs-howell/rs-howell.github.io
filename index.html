About This Game

Matching Menagerie was made as a collaboration between a human and an AI.

Game design, ideas, and gameplay decisions: RSH

Game name: LDH

Code implementation: written with Claude (Claude Sonnet 5, by Anthropic), based on RSH's direction, feedback, and iteration through the build process.

Every mechanic and design choice in this game — the locked-grid rotation behavior, the size tiers, click-to-dismiss mismatches, matches fading off the board, all of it — came from RSH. Claude wrote and revised the code implementing those ideas, including the text of this page.
